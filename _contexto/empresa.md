**O que é a TopServ:** agência de marketing americana para **home service contractors** (HVAC, encanamento, elétrica etc.). Constrói **autoridade de mercado** via um sistema integrado chamado **Brandformance**.

## Doutrina — Brandformance
Não vende ads, SEO ou vídeo como serviços avulsos. Constrói **marca + performance juntos** pra tornar o cliente a escolha óbvia no mercado dele. Tese: **anúncio não cria autoridade, amplifica**. Empresa escalando rumo a 8 dígitos; a divisão de paid (minha) é central nisso.

As **3 jobs of marketing** e o detalhe filosófico estão no doc "Brandformance and BED doctrine" (inclui o livro do JB). **BED (Brand Equity Domination)** é a camada de marca, obrigatória nos tiers Accelerator e Dominator; o **BED Calculator** dimensiona o "awareness floor" por geografia.

## Tiers e o que paid entrega (Programs 2026)
Entry padrão = **Builder ($5.000/mês)**. **Starter** é tier-ponte performance-only. Min. ad spend **$3.000**. Starter fee $2.000.

| Entregável paid | Starter | Builder $5K | Accelerator $8K | Dominator $10K |
|---|---|---|---|---|
| LSA | ✓ | ✓ | ✓ | ✓ |
| Meta Ads | ✓ | – | ✓ | ✓ |
| PPC | – | ✓ | ✓ | ✓ |
| Retargeting | – | ✓ | ✓ | ✓ |
| YouTube Ads | – | – | ✓ | ✓ |
| TikTok Ads | – | – | ✓ | ✓ |

## Alocação de budget (padrão da divisão)
- **Meta:** 90–95% conversão (Calls/Forms), 5–10% awareness. (Accelerator/Dominator têm exceções de BED via Brandformance Overlay.)
- **Google:** maioria em Search (Branded + Non-Branded). Máx. 5–10% em Performance Max. Proibido PMax-only.
