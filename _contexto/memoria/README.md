# Memória TSD (compartilhada)

Memória de trabalho do time de Paid da TopServ: estado de cada cliente, regras, receitas e armadilhas já pagas. Um arquivo = um fato. Esta pasta é `_contexto/memoria/` no workspace; os links abaixo são relativos a ela.

**Como usar:** quando um cliente ou assunto aparecer, abrir o arquivo dele antes de agir. **Como salvar:** aprendizado novo de TSD vira arquivo aqui (mesmo formato: frontmatter `name`/`description`/`metadata.type`, depois o fato, com **Why:** e **How to apply:** quando for regra) + uma linha neste índice. Antes de criar, procurar se já existe um arquivo sobre o assunto e atualizar ele. Datas sempre absolutas (YYYY-MM-DD). Sobe pro GitHub com `/syncar`.
