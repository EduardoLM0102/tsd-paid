Process 'Client Strategy Review' `15e1a5ee-fbcb-498b-a01d-6d6a49966f13`, monthly per client: Schedule & Intake (AM) → **Performance Reporting (Paid: Edu/Gui, 15 min, auto-advance)** → Host Review Call (AM). Task fields: review_label, review_cycle_start/end_date, call_date_time, intake_notes, additional_paid_ads_notes, call_discussion_checklist, platform_update_checklist, tasks_to_create.

**Paid's deliverable = one row in the CLIENT field 'Client Performance KPIs'** (custom object `4038154a-2315-4b1a-87a5-b94a21a0db4e`, client field `c72c4f7e-11c4-4b06-b720-1031f5f30bd9`, embedded_list): period_start_date + period_end_date (required, = review cycle dates), ad_spend, agency_fees, total_spend, qualified_leads, cpl, recommend_budget, budget_rationale. Examples on Tony Test Clients / TopServ Digital. Then mark the stage complete, which hands it to the AM.

AT has no draft state for that row: once created, the AM sees it. When Edu says "leave on draft", stage the values in a local file + Slack draft and write the row only after his OK.
